# 틈 · 운동 타이머

iPhone Safari용 개인 인터벌 타이머. 별도 빌드, 외부 라이브러리, 유료 도메인이 필요 없는 정적 웹앱입니다.

## 사용

- 운동·휴식 시간(각 1~3600초), 반복 세트(1~99회), 5초 준비를 설정합니다.
- 시작, 일시정지, 초기화, 구간 넘기기와 전환/마지막 3초 알림음을 지원합니다.
- 마지막 운동 세트 뒤 휴식 없이 종료합니다. 설정은 현재 브라우저에 저장됩니다.
- Safari 공유 → 홈 화면에 추가. 첫 온라인 접속 후 오프라인 준비 완료 표시를 확인하세요.
- 기기 음량을 올리고 소리 확인 버튼으로 먼저 확인하세요. 실제 iPhone에서 소리 재생을 확인하는 것이 좋습니다.

## 잠금 중 오디오 (시험 기능)

기본으로 켜진 오디오 모드는 전체 운동의 작은 박자음, 전환음, 마지막 3초, 완료음을 단일 WAV 오디오 트랙으로 만들어 재생합니다. 소리 생성은 네트워크 없이 기기에서 이뤄집니다. 백그라운드 JavaScript 타이머에 의존하지 않고 미디어 재생 위치로 화면을 동기화합니다. 최대 총 60분(오디오 약 29MB)이며 일시정지·이어 시작·구간 넘기기를 지원합니다. 지원 브라우저에서 잠금 화면의 미디어 제어도 연결합니다.

아이폰 Safari에서 시작 후 소리를 확인하고 화면을 잠가 테스트하세요. iOS 버전·브라우저·다른 미디어·통화에 따라 재생이 중단될 수 있는 시험 기능입니다. 탭 닫기·새로고침·앱 강제 종료 후 계속 재생은 지원하지 않으며 iPhone 진동을 보장하지 않습니다. 앱스토어의 네이티브 타이머 같은 백그라운드 실행을 보장하는 기능은 아닙니다.

이 모드를 끄면 기존 화면 전용 타이머로 동작합니다. 지원 브라우저에서 화면 자동 잠금을 방지하도록 요청하고, 화면 잠금·앱 이동으로 페이지가 숨겨지면 자동 일시정지합니다. 모든 모드에서 새로고침 시 운동 진행 상태는 초기화됩니다.

## GitHub Pages

이 폴더 내용을 공개 저장소의 main 브랜치 루트에 업로드합니다. Settings → Pages → Deploy from a branch → main / (root) → Save. 제공된 github.io 주소로 접속하세요. 공개 저장소이므로 소스와 웹페이지는 다른 사람도 볼 수 있으며, 개인 설정은 기기에만 저장됩니다.

## 개발

정적 HTTP 서버로 이 디렉터리를 제공하세요. 서비스 워커는 HTTPS 또는 localhost가 필요합니다. JavaScript 구문 검사는 `node --check app.js`, `node --check engine.js`, `node --check sw.js`로 가능합니다.
